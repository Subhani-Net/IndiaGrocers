# Search Intelligence — IndiaGrocers

Multi-language search dictionary for Indian grocery products.
Built from our 283-product catalog, enriched via BlinkIt/JioMart research.

## Structure

```
data/search-intelligence/
├── per-category/              # One JSON per product (generated by scraper)
│   ├── staples-grains/
│   │   ├── natco-basmati-rice-india-2kg.json
│   │   └── ...
│   ├── dal-lentils/
│   └── ...
├── regional-terms.json        # Tamil/Telugu/Hindi/Urdu/Kannada dictionary
├── brand-aliases.json         # Common brand spellings + typos
├── scraper.mjs                # BlinkIt + JioMart extractor (drip-feed)
├── merge-and-upload.mjs       # Processes JSON → builds dictionaries → MeiliSearch
└── README.md
```

## How to Use

### 1. Run scraper (one-time, unattended ~2 hours during off-peak)

```bash
node data/search-intelligence/scraper.mjs
```

Extracts search suggestions, product details, taxonomy, regional tags, 
dietary info, and competitor naming from BlinkIt + JioMart for all 283 products.

Output: `per-category/<category>/<handle>.json` — 283 files.

### 2. Run merge + upload (after scraper completes)

```bash
node data/search-intelligence/merge-and-upload.mjs
```

Reads all 283 per-product JSON files, deduplicates, builds:
- `synonyms.json` — all search alternates
- `regional-terms.json` — regional language mappings
- `brand-aliases.json` — brand name variants

Uploads to MeiliSearch synonyms and reindexes.

### 3. Verify

```bash
# Test search in browser or via API
curl -X POST http://localhost:7700/indexes/products/search \
  -H 'Content-Type: application/json' \
  -d '{"q":"aval","limit":5}'
```

## Adding New Products

When catalog grows:
1. Add new product handles to the scraper run list
2. Run scraper for new products only
3. Run merge + upload to update MeiliSearch

## Rate Limiting

Scraper respects:
- BlinkIt/JioMart rate limits (~1 req/6-10 seconds)
- Runs during off-peak hours only
- Random delays between requests
- Maximum 400 requests/hour
